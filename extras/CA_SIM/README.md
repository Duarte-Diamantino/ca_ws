# CA_SIM (código antigo)

Ficheiros do repositório [CA_SIM](https://github.com/Duarte-Diamantino/CA_SIM) @ `ecbc295` que não
passaram para os pacotes: versões antigas do MPC, do DWA, da GUI e dos geradores de splines, o mapa e
os STL do carro. Não são compilados. As versões em uso estão em `src/mpc_python`, `src/dwa_follower`,
`src/ca_gui` e `src/gui_pista`, e `src/pickup_description`.

O README original deste repositório (simulação no Gazebo no WSL2) está em
[`docs/gazebo_wsl_setup.md`](../../docs/gazebo_wsl_setup.md); as outras notas em [`docs/`](../../docs).
